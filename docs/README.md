# Active Documentation

This directory contains only active contracts used by the React/Vite and Flask
release. The typed application registry in `apps/web/src/appData.ts` is the
source of truth for workflow and binder definitions.

- `APPS_SCRIPT_6_FILE_CONTRACT.md` - the three User and three System bundles.
- `CABINET_WORKFLOW_MATRIX.md` - building, binder, and workflow routing.
- `CV_TEMPLATE_ROUTING_CONTRACT.md` - CV method and template routing.

Setup and owner deployment instructions are in the root `README.md`,
`OWNER_DEPLOYMENT.md`, and the launcher/install scripts. Historical handoffs,
plans, archived source trees, and scratch reports are intentionally not part of
the repository.
